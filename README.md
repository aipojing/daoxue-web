# 学伴 AI

> 面向家庭的 AI 学习陪伴工具：用提示、追问、练习和复盘帮助孩子自己学会，而不是直接把答案交给孩子。

[立即使用](https://xue.aipojing.xyz) · [备用地址](https://daoxue-web.xueban-ai.workers.dev) · [技术文档](docs/TECHNICAL.md) · [部署文档](docs/DEPLOY.md)

一个账号可以管理多个孩子。每个孩子都有独立的学习画像、会话、知识点记录和错题本，长期使用后，AI 会逐渐了解孩子学到了哪里、容易错在哪里、下一步适合学什么。

## 适合什么时候用？

| 你的需求 | 推荐入口 | 学伴 AI 会怎么做 |
|---|---|---|
| 作业遇到不会的题 | 解题辅导 | 判断卡点，逐步提示，引导孩子自己完成 |
| 已经做完，想检查答案 | 解题辅导 | 批改过程，定位第一处错误并带着订正 |
| 错题总是反复出现 | 错题本 | 记录错因、关键步骤和复测题，到期再次练习 |
| 想系统学习一项内容 | 自学陪伴 | 安排每日任务、旧知识保温、学习、语音课件、测验和复盘 |
| 家长想了解学习情况 | 自学陪伴 | 生成每课输出和每日家长反馈，沉淀薄弱点与下一步计划 |

## 3 分钟开始使用

1. 打开[学伴 AI](https://xue.aipojing.xyz)，使用邀请码注册并登录。
2. 登录后先进入「AI 服务」页，填写自己的 DeepSeek API Key；需要拍照识题时再填写视觉服务 Key。
3. 点击“添加学生”，填写孩子的年级、教材和学习画像。信息不确定时可以留空，以后随时能改。
4. 进入学生主页，根据当前需求选择“解题辅导”或“自学陪伴”。
5. 第一次使用建议先做一道真实题目，或从一个明确的小目标开始，不需要一次填写大量背景资料。

如果这是你自己部署的新站点，第一个注册账号会自动成为管理员；已有管理员的站点，后续注册需要邀请码。

关于 AI Key：

- Key 按账号保存，同一账号下的所有学生共用；保存后只显示尾号，不会回显完整值。
- 每个账号只能看到和修改自己的 Key，看不到其他账号的配置。
- 对话、错题提取、自学后处理和学习画像提炼都会消耗当前生效的 DeepSeek Key。
- 每个账号可以在「AI 服务」页设置画像提炼间隔和每日上限，同一账号下的学生共用该策略。
- 管理员可以为站点配置“共享 AI 服务”作为兜底；只有管理员明确开启共享兜底时，没有个人 Key 的账号才会使用共享服务。
- 上一条共享兜底只适用于聊天、OCR 等原有能力。语音课件严格使用当前家长账号自己的 provider Key 和模型选择；缺 Key、Key 无效或额度耗尽时停止新生成，绝不会改用平台共享 Key 或跨服务商兜底。

## 解题辅导怎么用

解题辅导支持数学、语文、物理、英语、化学和历史。

### 1. 选择学科并提交题目

尽量同时提供：

- 完整题目和选项、图表、实验条件；
- 孩子已经写出的答案或过程；
- 卡住的位置，或者自己觉得可疑的那一步；
- 希望采用的方式：只给提示、分步导学、批改复盘或完整讲解。

例如：

> 这是初三化学题。我已经算到溶质质量是 8g，但不知道下一步怎么求质量分数。先不要直接给答案，请提示我第一步。

没有说明模式时，系统会根据已有作答自动选择批改复盘或分步导学。

### 2. 跟着提示继续作答

AI 会先判断真正的卡点，再给当前所需的最小提示。孩子可以直接回复自己的下一步、计算结果或疑问，AI 会根据回答继续引导。

遇到综合题、推理题时，可以打开会话右上角的“深度思考”。普通练习保持关闭即可，响应更快。

### 3. 拍照识题

如果你在「AI 服务」页配置了图片识别服务（或站点共享服务可用），输入框旁会出现相机按钮：

1. 拍照或选择题目图片；
2. 等待系统转写为文字；
3. 对照原图检查数字、符号和图形条件；
4. 修正识别错误后再发送。

图片识别用于减少录入工作，最终仍应以原题为准。

### 4. 保存值得复习的错题

完成讲解后，点击回答下方的“存入错题本”。系统会整理：

- 题目与知识点；
- 孩子的原答案；
- 第一处关键错误；
- 错因标签和正确步骤；
- 下次复测提醒与同类复测题。

## 自学陪伴怎么用

自学陪伴适合每天固定时间学习新内容、预习补弱或进行专项提升。方向不限于六个学科，也可以填写编程、写作等目标。

### 第一次进入

添加学生时尽量完成四步画像：

1. 学习方向与目标；
2. 当前位置和薄弱点；
3. 学习习惯、可用时间与兴趣；
4. 家长关注点和其他说明。

画像不是考试，也不要求一次填完。信息越真实，后续安排越贴合孩子。

### 每天的学习流程

进入自学会话后，可以直接使用输入框上方的快捷按钮：

语音课件采用逐步开放开关。管理员未开启时，原有 OpenMAIC 交接流程保持不变；开启后，自学会话只在每日学习模式中显示站内课件卡片，画像采集不会生成或解析课件任务。

功能开启后的站内流程：

```text
开始今天的学习
  ↓
任务确认 → 旧知识保温 → 新知识拆解
  ↓
确认站内语音课件任务 → 后台生成脚本、老师/AI 同学语音和可选配图
  ↓
离开页面也可继续生成 → 返回课件库播放、定位进度、使用“我没听懂”和课内检查点
  ↓
开始正式测验 → 回到自学会话一题一答 → 错因分析 → 错题卡 → 下一步安排
  ↓
点击“今天结束”生成每日家长反馈
```

课件脚本中的老师讲解、AI 同学提问/误区、备用解释、语音和可选配图都在生成阶段预先完成，播放时不会再调用模型。配图失败时课件仍可完成并显示警告；脚本或必需语音不完整时不会标记为可播放。

家长先在“AI 服务”页配置服务商 Key、测试连接并保存各用途的默认模型；新建语音课件或确认会话内课件卡片时，可以为本次课件重新选择脚本、老师语音、AI 同学语音和可选配图模型。本次选择只写入新课件快照，不会反向修改账户默认值。

管理员未开启语音课件时，系统仍会生成原有 OpenMAIC 课件提示词；学习完成后回到本站继续测验。新部署的 `courseware_enabled` 默认值是 `0`，必须在完成部署冒烟后由管理员明确开启。

### 语音课件与正式测验

- 课件在后台队列中生成，可以离开页面后再从“语音课件”库返回查看进度。
- 播放器支持老师与 AI 同学对话时间线、暂停/继续、上一段/下一段、倍速、拖动定位和断点续学。
- “我没听懂”只播放预生成的备用解释，不会临时调用模型或产生新的 provider 费用。
- 课内检查点只保存课件进度，不直接写入 L1–L4 掌握证据。
- “开始正式测验”会复用或创建一个归属当前孩子的每日自学会话；一题一答的正式回答仍按原自学流程沉淀知识点和错题卡。
- 已完成的课件在个人 Key 被移除、目录模型被停用或功能开关关闭后仍可播放并继续正式测验；开关关闭只阻止创建新的课件。

系统使用 L1–L4 表示掌握程度：

| 等级 | 含义 |
|---|---|
| L1 | 刚接触，需要重新讲解或示范 |
| L2 | 在提示下能完成，还不稳定 |
| L3 | 可以独立复述和完成基础任务 |
| L4 | 能迁移到新情境，并解释为什么 |

低于 L3 时，系统会优先巩固当前知识链，而不是急着推进新内容。

## 错题本和复测

进入学生主页的“错题本”，可以按学科和状态筛选：

- “待复测”表示还需要再次练习；
- 复测通过后标记为“已通过”；
- 没通过可以继续保留，稍后再次复测；
- 不再需要的记录可以删除。

建议不要把所有题都存进去。真正值得保存的是暴露了概念漏洞、方法选择错误或表达问题的题目。

## 家长和管理员怎么用

普通家长可以：

- 管理自己账号下的多个学生；
- 修改学生画像；
- 查看各学生的会话和错题；
- 在不同孩子之间切换，记录不会混在一起。

管理员也在「AI 服务」页配置自己的个人 Key 和画像提炼策略。

管理员在“设置”页额外维护“站点共享 AI 服务”：

- 配置共享 DeepSeek API Key 与可选的图片识别服务；
- 用开关控制是否允许未配置个人 Key 的账号使用共享服务（兜底）；
- 生成、停用和管理邀请码；
- 调整每个账号的每日消息上限。

所有 API Key 只会显示掩码，不会在页面中完整回显。

## 使用建议

- 让孩子先说自己的想法，即使只写出第一步，也比只发题目效果好。
- 一次集中解决一个卡点；问题太多时，让 AI 逐题处理。
- AI 给出提示后，先让孩子回答，再继续看下一步。
- 拍照题务必核对转写结果，尤其是负号、上下标、单位和图形关系。
- 重要结论和计算结果仍要对照教材、老师要求或标准答案确认。
- 自学模式尽量完成“学习—测验—今天结束”的闭环，第二天的安排才会更准确。

## 常见问题

### 为什么 AI 不直接给答案？

默认目标是帮助孩子形成解题过程。确实需要完整题解时，可以明确说“请完整讲解”，系统仍会说明关键依据和步骤。

### 为什么没有相机按钮？

图片识别是可选功能，需要在「AI 服务」页配置视觉服务 Key（个人配置，或管理员开启的站点共享服务）。没有配置时仍可粘贴或输入文字题目。

### 为什么今天不能继续发送？

账号达到了管理员设置的每日消息上限。额度按天恢复，也可以联系管理员调整。

### 忘记密码怎么办？

目前没有自助找回密码功能，需要联系站点管理员处理。账号也暂未提供邮箱验证，适合家庭或小范围邀请使用。

### AI 的记录会不会串到另一个孩子？

每名学生的会话、画像、知识点和错题分别保存。发送前仍建议确认页面顶部显示的是正确学生和学科。
