# 冒烟清单

每次大改后过一遍（本地 `npm run build && npm run dev:worker` 或线上）：

1. [ ] 未登录访问 `/` → 跳转登录页
2. [ ] 注册（首个账号免邀请码成为管理员；后续账号需邀请码）
3. [ ] 登录 / 退出登录
4. [ ] 添加学生（姓名、年级、教材、颜色）→ 列表显示
5. [ ] 编辑 / 删除学生（删除有二次确认）
6. [ ] 学生主页四学科入口 → 新建会话
7. [ ] 发送数学题 → SSE 流式回复、公式渲染正常
8. [ ] 开启「深度思考」再发一条 → 显示思考过程折叠块
9. [ ] 点「存入错题本」→ 错题本出现结构化卡片
10. [ ] 错题本筛选 / 复测通过 / 未通过顺延 / 删除
11. [ ] 对话后学生主页画像自动生成（10 分钟节流，可先看无画像态）
12. [ ] 手动编辑画像并保存
13. [ ] 设置页：生成邀请码 → 隐身窗口注册第二账号 → 数据完全隔离
14. [ ] 管理员调整用户每日上限；用量达到上限后发消息被拒
15. [ ] 手机宽度（≤767px）：聊天全屏、抽屉侧栏、各页面无横向滚动
